About

Kâbusan is an independent creator that produces short animated horror films and publishes them on YouTube (@kabusan0), Instagram and TikTok.

Kâbusan Panel is a desktop tool that runs only on the creator's own computer. It is used exclusively by the channel owner to:

  • upload the channel's own finished videos to the channel's own YouTube account, with titles, descriptions and tags prepared by the creator, and optionally schedule their publication;
  • view the channel's own statistics (views, likes, comments, subscribers, average view percentage) next to the same episode's statistics on other platforms.

The tool is not distributed, sold or offered to anyone else. It has no public sign-up. The only Google account that uses it is the channel owner's account.

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service.

Privacy Policy

Last updated: 7 November 2026

Kâbusan Panel uses YouTube API Services. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

When the channel owner connects a YouTube account, the tool requests these Google OAuth scopes:

  • youtube.upload: to upload the channel's own videos;
  • youtube.readonly: to read the channel's own channel and video information (titles, publish dates, view, like and comment counts);
  • yt-analytics.readonly: to read the channel's own YouTube Analytics reports (views, average view duration and percentage, shares).

The tool does not access other users' data, does not read comments' authors, and does not access any data that is not related to the connected channel.

How the data is used

The data is displayed to the channel owner on their own computer, to compare how each episode performs across platforms and to publish new episodes. It is not used for advertising, profiling, or any other purpose, and it is never sold, shared with or transferred to third parties.

How the data is stored

  • OAuth tokens are stored only on the channel owner's computer, in a local file outside the project folder. They are never sent anywhere except to Google's own servers when calling the API.
  • The tool keeps a local log of the channel's own view counts (one snapshot per refresh) to show growth over time. This log is stored only on the owner's computer.
  • No data is stored on any server operated by Kâbusan. There is no server: the tool runs at localhost.
  • API data is refreshed regularly. Stored statistics are deleted when the owner disconnects the account or deletes the tool's data folder, and in any case within 30 days of the data no longer being refreshed.

Cookies and device information

The tool does not use cookies for tracking and does not collect device information. It does not store, access or collect information on any user's device other than its own local files on the owner's computer.

How to revoke access and delete data

  • In the tool: press Disconnect on the YouTube card. This deletes the stored tokens immediately.
  • At Google: remove the tool at Google security settings → Third-party apps with account access.
  • To delete stored statistics, delete the tool's data folder or contact us (below) and we will delete it within 7 days.
